# 探索记录与停止理由

本表是方向级索引，不是每轮指标清单；不把所有结果统一叫“不显著”。旧任务结果与正式任务分开解释，作废实验不纳入结论。

|方向|为什么尝试|最终保留的判断|后来者应先检查|
|---|---|---|---|
|经济分组、共同编码、公式残差|保留经济关系，减少冗余|未建立跨条件稳定优于合适非经济对照的证据；部分旧任务有局部收益|同维度、同参数、随机分组及不同任务口径|
|经济图、删列、派生指标|让结构先验参与压缩|图约束、删列等未形成稳定的经济特定优势|是否只是减少维度或新增信息的效果|
|变化量、历史基准及趋势偏离|寻找相对企业自身历史的异常|没有成为正式主模型的稳定增量|历史窗口、缺失、可用时点、分母与尺度|
|TabNet/VIME及表格模型适配|学习变量选择和交互|未选为正式主干，不能据此断言原方法无效|数据量、输入一致性、预训练信息条件|
|近邻、案例检索与联合学习|经营相似状态可能有额外线索|未形成足够稳的年度风险排序增量|近邻是否包含主模型之外的条件信息|
|延迟、不完整监督修正|减少尚未通报正例被当负例的影响|历史记录倾向外推受时期漂移影响；含错位索引的旧M1结果作废|标签修订台账、索引一致性、倾向可识别性|
|审计新增与条件调节|审计改变财务状态的风险含义|信息增量成立，结构优越性未成立|无审计、普通接入与FiLM三方对照|
|消息精度组合|少传字节而保持最终核查输出|899 B方案在三个年度保持名单与Top2集合|尺度只用训练数据拟合；核对实际打包|
|dCor/MID|减少表示泄露|MID在指定攻击下给出可测量取舍，仍有残余泄露|同架构、重新适配攻击器、允许误差与公共信息基线|
|历史回放与条件重训|降低年度维护计算成本|低成本微调有适用边界，保留监测与回退|旧/新年度保持、缓存版本与数据修订|

经济先验并非被证明无价值，现有实验只是没有建立该项目中的稳定算法优势。模拟研究有助于定位适用条件，但必须依据机制，并包含失效条件；不能按待证明方法量身生成容易取胜的数据。

代码快照来源见仓库根目录`provenance.csv`。原始完整历史档案未随公开包发布，缺少逐轮日志的方向只作研究经历，不新增具体数值或统计判断。
