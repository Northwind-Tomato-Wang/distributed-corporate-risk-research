# 方法与证据边界

## 条件融合

节点编码 h_i=f_i(x_i)，审计编码为c。财务调节：

h_2'=h_2+r[gamma(c)⊙h_2+beta(c)]。

r为审计匹配标志。调节潜在表示，不是直接给原始指标加权；普通拼接网络也能学习交互。正式类见research_snapshots中的FilmKeepX3。六模型校准logit平均形成最终排序。

## 隐私副模型

dCor惩罚输入与表示的距离依赖。MID发送z=mu(x)+sigma(x)⊙epsilon，并把归一化高斯KL以0.1强度加入任务目标。KL可提供输入—表示互信息的上界约束，但不是差分隐私预算。保护版本采用共享编码器、多个融合头，与正式六独立模型不能混算。

## 通信

训练确定量化尺度，消息解码后由原模型预测。81种组合中54种通过全部要求，选择其中最小载荷。候选在评价年度的保持属于实证，不能作为对未来普遍保持的证明。

## 维护

冻结节点编码与审计条件编码，训练其余融合部分。新增/修正样本与历史回放各占更新批次一半。监测退化时评估全量重训，失败保留旧版。历史表示缓存必须有版本键；原始输入修订或编码器变化时不能无条件复用。

## 不能合并的数字

主模型的三年排序、MID五种子攻击、两期维护回放属于不同实验。主模型精度与MID恢复率不是同一模型配置。0.37秒是连续增量，不是带重训和监测的完整条件更新成本。
